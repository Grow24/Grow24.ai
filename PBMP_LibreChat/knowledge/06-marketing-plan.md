# Marketing plan — Product X India

1. Mumbai — densest existing relationships, fastest reference cycle
2. Delhi — public-sector pipeline, slower but lower operational risk
3. Bangalore — enterprise parks, later because conversion is still prospect-heavy

This is a plan, not a decision. The Executive Analyst must still retrieve sales and recommend.
