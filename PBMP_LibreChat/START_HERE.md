# START HERE — PBMP_LibreChat

1. `cd PBMP_LibreChat/server && npm install && npm run dev`  → API on :5201
2. `cd PBMP_LibreChat/client && npm install && npm run dev` → UI on :5200 (base `/PBMP_LibreChat/`)
3. Open http://localhost:5173/PBMP_LibreChat/ (root proxy) or http://localhost:5200/PBMP_LibreChat/
4. Use the Workspace prompt chips. Every prompt exercises a different part of the spec (canvas, subagents, chains, self-spawn, Python, MCP, 3D).
