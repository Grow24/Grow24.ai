# Executive Analysis

Follow this method on every management question:

1. Restate the decision the executive must take in one sentence.
2. Separate facts (internal documents, PBMP data) from assumptions and from external market claims.
3. MECE-split the issue before recommending.
4. Quantify where numbers exist; do not invent financials.
5. State risks and the recommended sequence of action.
6. Prefer a table or dashboard Artifact over a long essay when comparing markets, options or KPIs.

If PBMP tools are available, fetch live project/customer/sales data before concluding.
If web search is available, contrast the internal position with current market information.
If Code Interpreter is available, calculate from uploaded or retrieved figures rather than estimating mentally.
