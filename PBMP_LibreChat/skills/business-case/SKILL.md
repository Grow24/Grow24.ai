# Business Case

Required sections:

1. Context and decision
2. Options considered
3. Economics (revenue, cost, ROI) using retrieved or uploaded numbers
4. Risks and mitigations
5. Implementation sequence
6. Recommendation (one primary path)

For market-entry cases, compare markets in a table and recommend an order of launch, not a vague “consider all”.
