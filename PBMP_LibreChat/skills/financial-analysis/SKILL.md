# Financial Analysis

- Use Code Interpreter or PBMP sales/actuals tools for arithmetic.
- Show inputs, formula, and result.
- Call out plan vs actual, margin, ROI, and the three largest drivers of variance.
- Never invent currency figures. If data is missing, say what must be fetched.
